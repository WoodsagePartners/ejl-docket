# EJL Docket

Live, multiplayer workflow docket for Erin Johnson Legal's estate-planning
process. Backed by Supabase (Postgres + Realtime), deployed on Vercel.

- Everyone with the passcode sees the same board, live.
- Click a step to seal it as an automation candidate.
- Click the "+" between any two steps to insert a new one mid-flow.
- Duration/savings estimates sync across every viewer.
